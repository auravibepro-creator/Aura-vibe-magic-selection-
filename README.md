# Aura Vibe Magic Selection - Pattern Master Studio

An advanced React & TypeScript studio for deep pattern decomposition, motif extraction, embroidery enhancement, and vector SVG/PNG export.

## Features
- **Batch Upload & Camera Capture**: Ingest images directly via file upload or camera.
- **Deep Pattern Decomposition**: Hierarchical layer separation (Macro, Meso, Micro levels).
- **Embroidery Contrast Enhancement**: 'Make It Premium' high-contrast filter.
- **Multi-format Vector Export**: Export individual or all layers as SVG or PNG.
- **Voice Control**: Voice-activated recognition for hands-free studio controls.
